# OSTEOMED - Centro Médico y Dental

Sitio web oficial para OSTEOMED, centro médico y dental ubicado en Punta Arenas, Región de Magallanes, Chile.

## Tecnologías

- **Frontend:** React + Vite
- **Estilos:** Tailwind CSS
- **Animaciones:** Framer Motion
- **Iconos:** Lucide React
- **Routing:** React Router DOM
- **Deploy:** Vercel

## Instalación

1. Clona el repositorio
2. Instala dependencias: `npm install`
3. Copia `.env.example` a `.env` y configura las variables
4. Ejecuta en desarrollo: `npm run dev`
5. Construye para producción: `npm run build`
